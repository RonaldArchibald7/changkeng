前言
该方案作为一套简单通用的后台框架模板，适用于静止的后台管理系统开发。基于Vue3 + pinia + typescript，引用Element Plus组件库，方便开发。实现逻辑，适合外包项目，快速交付。

功能
元素加
维生素3
皮尼亚
TypeScript
登录/注册
仪表板
表格/表格
图表📊
富文本/markdown编辑器
图片拖拽/需上传
权限管理
三级菜单
自定义图标
主题切换
安装步骤
由于使用vite3，node版本需要14.18+

git clone https://github.com/lin-xin/vue-manage-system.git      // 把模板下载到本地
cd vue-manage-system    // 进入模板目录
npm install         // 安装项目依赖，等待安装完成之后，安装失败可用 cnpm 或 yarn

// 运行
npm run dev

// 执行构建命令，生成的dist文件夹放在服务器下即可访问
npm run build
